# Going live: setup checklist

The YouTube channel [@vibecamp-show](https://www.youtube.com/@vibecamp-show) has live streaming unlocked since 2026-10-20.

## One-time setup
1. **OBS** (free): obsproject.com
2. **Scene "Vibe Camp"**
   - *macOS Screen Capture* → **laptop display only**. Keep the messy stuff on the big monitor.
   - *Application Audio Capture* → the browser or app running Meet. This replaces BlackHole.
   - *Audio Input Capture* → your mic.
   - Optional: the theme song as a *Media Source* for intro and outro.
3. **Stream key:** YouTube Studio → *Go live* → *Stream* → copy the key. It's a password: never show it on screen.
4. OBS → *Settings → Stream → YouTube*, then paste the key or link the account.
5. *Settings → Output:* 1080p30, about 6000 kbps. *Audio:* 48 kHz.

## Before each show
- [ ] Do Not Disturb on; close mail and chat on the shared screen
- [ ] Headphones on, so the bots don't hear themselves
- [ ] Schedule the stream in YouTube Studio to get a shareable link
- [ ] Do a quick private test stream and check that Meet, you and the bots are all audible

## During and after
- Intro with the theme song, then *Start streaming* (about 20 s latency)
- The stream becomes the raw VOD. A cleaned-up remaster can go up as a separate video.
- Want X too? Restream fans one OBS feed out to YouTube and X.
- In future, "Jimmy, go live" may do this from the call itself (vibeconf-app#865).
